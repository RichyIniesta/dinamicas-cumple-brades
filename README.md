# Dinámicas Cumple Bradesco

Base inicial para una experiencia web de dinámicas de cumpleaños de Bradesco México.

## Estructura

- `index.html` — estructura semántica, navegación, hero, dinámicas, statement y modal.
- `styles.css` — sistema visual, layout responsive, tarjetas y componentes.
- `script.js` — interacciones iniciales del modal.

## Dirección visual

La interfaz toma como referencia la página oficial de marca de Bradesco: composición editorial, mucho espacio en blanco, tipografía sans-serif, jerarquía tipográfica grande y uso puntual del rojo Bradesco.

Referencia visual:
https://banco.bradesco/marca/index.shtm
