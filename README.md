# Dinámicas Cumple Bradesco

Interfaz de apoyo para la presentadora durante las dinámicas de cumpleaños de Bradesco México. Está pensada para proyectarse en pantallas del comedor y funcionar como un pequeño centro de control visual.

## Arquitectura actual

La aplicación funciona como una experiencia de una sola página con tres accesos principales:

1. **Inicio de presentación** — escenario de diapositivas con controles anterior/siguiente y pantalla completa.
2. **Ruleta de poderes** — ruleta interactiva con resultado aleatorio.
3. **Temporizador** — cuenta regresiva configurable, con iniciar, pausar, continuar y reiniciar.

Desde cualquier herramienta se puede regresar al **Menú principal**.

## Archivos

- `index.html` — estructura de la experiencia y contenido provisional de las diapositivas.
- `styles.css` — sistema visual responsive y componentes de pantalla.
- `script.js` — navegación, presentación, ruleta y temporizador.

## Dirección visual

La dirección toma como referencia la página oficial de marca de Bradesco: composición editorial, espacio blanco, tipografía sans-serif, jerarquía tipográfica grande y rojo como acento protagonista. La referencia oficial también contempla recursos de marca y Bradesco Sans. 

Referencia:
https://banco.bradesco/marca/index.shtm
